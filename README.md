# Чат для Telegram на GREEN-API

Тестовое задание на позицию «Фронтенд разработчик React».

Это небольшой веб-чат: вводишь данные инстанса GREEN-API, указываешь номер собеседника, пишешь ему и видишь его ответы. Делал под Telegram, а не под MAX: в ТЗ такой вариант разрешён, а аккаунта в MAX у меня нет. Интерфейс сделан простым, без лишних функций, как и просили.

## Что умеет

- вход по `idInstance` и `apiTokenInstance` (сразу проверяется, что инстанс авторизован);
- создание чата по номеру телефона;
- отправка текстовых сообщений через `SendMessage`;
- получение ответов через `ReceiveNotification` и `DeleteNotification`;
- история чатов хранится в браузере, поэтому после перезагрузки страницы ничего не пропадает;
- светлая и тёмная тема, нормально выглядит на телефоне.

Файлы, картинки и прочее не поддерживается: в задании нужен только текст.

## Как запустить

Сначала нужен инстанс GREEN-API:

1. Зарегистрироваться на [green-api.com](https://green-api.com) и создать Telegram-инстанс.
2. В личном кабинете авторизовать его через QR-код из приложения Telegram.
3. В настройках уведомлений оставить URL пустым и включить уведомления о входящих сообщениях, о сообщениях с телефона и о сообщениях с API.
4. Скопировать `idInstance` и `apiTokenInstance` (и `apiUrl`, если запросы почему-то не проходят).

Дальше стандартно:

```bash
npm install
npm run dev
```

Открыть http://localhost:5173 и войти. Номер собеседника вводится цифрами с кодом страны, например `79991234567`.

Продакшен-сборка: `npm run build`.

## Как устроено

```
src/
  api.js                      запросы к GREEN-API и разбор уведомлений
  storage.js                  localStorage (данные входа и чаты)
  hooks/useNotifications.js   цикл получения входящих сообщений
  components/Login.jsx        экран входа
  components/Messenger.jsx    состояние чатов и отправка
  components/Sidebar.jsx      список чатов и создание нового
  components/ChatWindow.jsx   переписка и поле ввода
```

Получение сообщений сделано обычным long-polling: запрашиваем уведомление, обрабатываем и сразу удаляем его, иначе API вернёт то же самое ещё раз. Сообщения, которые я отправил через API, приходят ещё и в виде уведомлений, поэтому есть проверка по `idMessage`, чтобы не показывать их дважды.

## На что обратить внимание

- `apiUrl` по умолчанию строится из `idInstance` (например, `https://4100.api.green-api.com`). Если у вас другой, его можно вписать на экране входа в поле «Дополнительно».
- Telegram у GREEN-API сейчас в бете, так что возможны сбои на их стороне.
- На бесплатном тарифе Developer ограничено число собеседников в месяц. Когда лимит кончается, API отвечает ошибкой 466, и её текст показывается под неотправленным сообщением. Лимит занимают и входящие из групп.
- Данные инстанса лежат в localStorage браузера. На чужом компьютере после работы лучше нажать «Выйти».
